# Roadmap: Universal Multi-Agent Platform

## 🚀 Планируемые фичи

### 1. Мульти-сессии (Multi-Session Support)
**Приоритет:** Высокий  
**Статус:** Планируется

#### Описание
Возможность работать с несколькими сессиями одновременно:
- Список старых сессий в sidebar
- Переключение между сессиями
- Параллельная работа нескольких агентов
- Автогенерация названий сессий из первого сообщения

#### Что уже готово
- ✅ Персистентность сессий в `data/sessions/*.json`
- ✅ SessionManager поддерживает множество сессий
- ✅ WebSocket по session_id (`/ws/{session_id}`)
- ✅ Изолированный ConversationContext для каждой сессии
- ✅ `startNewSession()` в chatStore

#### Что нужно реализовать
- [ ] API endpoint `GET /sessions` — список сессий с метаданными
- [ ] API endpoint `DELETE /sessions/{id}` — удаление сессии
- [ ] UI: Sidebar со списком сессий
- [ ] UI: Переименование сессий
- [ ] UI: Поиск по сессиям
- [ ] UI: Параллельные вкладки/split-view для нескольких сессий
- [ ] Автоочистка старых сессий (>30 дней)

#### Архитектура
```
┌─────────────────────────────────────────────────────┐
│                    Frontend                          │
├──────────────┬──────────────┬──────────────────────┤
│  Session A   │  Session B   │  Session C           │
│  "Анализ     │  "Создание   │  "Встречи на         │
│   файлов"    │   презы"     │   неделю"            │
│  [активна]   │  [в работе]  │  [завершена]         │
└──────┬───────┴──────┬───────┴──────────────────────┘
       │              │
       ▼              ▼
┌──────────────┬──────────────┐
│ WS /ws/aaa   │ WS /ws/bbb   │  ← Параллельные WebSocket
└──────┬───────┴──────┬───────┘
       │              │
       ▼              ▼
┌─────────────────────────────────────────────────────┐
│                    Backend                           │
│  SessionManager                                      │
│  ├── session_aaa: ConversationContext               │
│  ├── session_bbb: ConversationContext               │
│  └── session_ccc: ConversationContext               │
└─────────────────────────────────────────────────────┘
```
