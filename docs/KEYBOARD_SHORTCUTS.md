# Горячие клавиши

## Навигация
| Клавиша | Действие |
|---------|----------|
| `Ctrl/Cmd + K` | Фокус на поле ввода |
| `Esc` | Закрыть открытые меню |
| `Ctrl/Cmd + /` | Открыть справку |

## Редактирование
| Клавиша | Действие |
|---------|----------|
| `Enter` | Отправить сообщение |
| `Shift + Enter` | Новая строка в поле ввода |
| `Ctrl/Cmd + Backspace` | Удалить слово |

## Режимы работы
| Клавиша | Действие |
|---------|----------|
| `Ctrl/Cmd + 1` | Переключить на режим Query |
| `Ctrl/Cmd + 2` | Переключить на режим Agent |
| `Ctrl/Cmd + 3` | Переключить на режим Plan |

## Интерфейс
| Клавиша | Действие |
|---------|----------|
| `Ctrl/Cmd + ,` | Открыть настройки |
| `Ctrl/Cmd + H` | Открыть меню помощи |

---

**Примечание:** Горячие клавиши для режимов работы находятся в разработке и будут доступны в следующих версиях.
