# Universal Multi-Agent Platform — Документация

## Что это за система?

Universal Multi-Agent Platform — это интеллектуальный ассистент на базе AI, который помогает автоматизировать рабочие задачи через интеграции с различными сервисами. Система использует технологию ReAct (Reasoning + Acting) для автономного выполнения сложных многошаговых задач.

**Основные возможности:**
- 🤖 Автономное выполнение задач через AI-агентов
- 🔌 Интеграции с Google Workspace, 1С, Project Lad
- 📊 Анализ данных и генерация отчетов
- 📧 Управление почтой и календарем
- 📄 Работа с документами и таблицами

---

## Быстрый старт

### Шаг 1: Выберите режим работы
В нижней части окна чата выберите один из режимов:
- **Query** — для чтения данных и получения информации
- **Agent** — для быстрого выполнения задач
- **Plan** — для сложных задач с планированием

### Шаг 2: Настройте интеграции
Откройте меню "Приложения" (иконка смартфона) и подключите нужные сервисы:
- Google Workspace (Gmail, Calendar, Drive, Sheets, Docs, Slides)
- 1С Бухгалтерия
- Project Lad

### Шаг 3: Начните работу
Просто опишите задачу в чате, например:
- "Покажи встречи на этой неделе"
- "Найди письма от alice@example.com"
- "Создай документ с отчетом"

## Режимы работы

### 🔍 Query (Вопрос)
**Когда использовать:** Для чтения данных и получения информации

**Особенности:**
- Только чтение, без изменений
- Действия скрыты, показывается только результат
- Идеально для: поиска файлов, просмотра календаря, чтения писем

**Примеры:**
- "Посмотри встречи на этой неделе"
- "Найди файл отчет.xlsx"
- "Покажи данные из 1С за январь"

---

### 🤖 Agent (Агент)
**Когда использовать:** Для быстрого выполнения задач

**Особенности:**
- Полный доступ к возможностям (чтение и запись)
- Действия видны в реальном времени
- Автономное выполнение без подтверждений

**Примеры:**
- "Создай документ с отчетом"
- "Отправь письмо на alice@example.com"
- "Объедини данные из двух таблиц"

---

### 📋 Plan (План)
**Когда использовать:** Для сложных многошаговых задач

**Особенности:**
- Генерация плана перед выполнением
- Возможность редактировать план
- Подтверждение перед выполнением
- Прогресс-бар выполнения

**Примеры:**
- "Создай интеграцию с новым CRM"
- "Настрой автоматизацию для отчетов"
- "Сгенерируй код для API"

## Интеграции

### Google Workspace
**Доступные сервисы:**
- 📧 **Gmail** — отправка, чтение, поиск писем, управление метками
- 📅 **Calendar** — просмотр и создание встреч
- 📊 **Sheets** — работа с таблицами, анализ данных
- 📄 **Docs** — создание и редактирование документов
- 🎯 **Slides** — создание презентаций
- 📁 **Drive** — поиск и управление файлами

**Настройка:** Меню "Приложения" → Google Workspace → Авторизация через OAuth

---

### 1С Бухгалтерия
**Возможности:**
- Запросы к OData API
- Получение данных о проводках, остатках, выручке
- Работа со справочниками и документами

**Примеры запросов:**
- "Покажи проводки за январь"
- "Остатки на складах"
- "Выручка по учету"

**Настройка:** Меню "Приложения" → 1С Бухгалтерия → Укажите URL и учетные данные

---

### Project Lad
**Возможности:**
- Просмотр проектов и портфелей
- Диаграммы Ганта
- Работы проекта и вехи
- Показатели и аналитика

**Примеры запросов:**
- "Покажи проекты в PL"
- "Диаграмма Ганта проекта X"
- "Показатели проекта за квартал"

**Настройка:** Меню "Приложения" → Project Lad → Укажите URL и токен

## Примеры использования

### Работа с календарем
```
Вы: "Покажи встречи на завтра"
Агент: [Показывает список встреч]

Вы: "Создай встречу с командой на 15:00"

```

Вы: "Отправь письмо с отчетом на manager@example.com"

```

```
Вы: "Проанализируй данные из таблицы 'Отчет.xlsx'"

```

Вы: "Остатки на складах"
Агент: [Получает данные об остатках]
```

## FAQ

**Q: Как начать работу?**  
A: Выберите режим (Query/Agent/Plan), настройте интеграции в меню "Приложения", и просто опишите задачу в чате.

**Q: Безопасны ли мои данные?**  
A: Да, все данные хранятся локально в вашей сессии. Интеграции используют OAuth для безопасной авторизации.

**Q: Можно ли отменить действие?**  
A: В режиме Plan вы можете редактировать план перед выполнением. В режиме Agent действия выполняются сразу, но вы можете остановить выполнение.

**Q: Как работает анализ данных?**  
A: Система может выполнять Python код для расширенного анализа. Результаты отображаются в виде диаграмм и таблиц.

**Q: Поддерживаются ли другие языки?**  
A: Система работает на русском языке. Все ответы и reasoning выполняются на русском.
