## 🔍 Структура данных Project Lad

### Endpoint для получения показателей:
```
GET /v1/project/{project_id}/version/{version_id}/item-indicator-value/list
```

### Параметры запроса:
- `from_date`: дата начала (формат: YYYY-MM-DD)
- `to_date`: дата окончания (формат: YYYY-MM-DD)
- `indicator_ids`: опционально, массив ID показателей для фильтрации

### Ожидаемая структура ответа:
```json
{
  "result": [
    {
      "indicator_id": "...",
      "indicator_name": "Ресурсы",
      "resource_name": "Иванов И.И.",
      "value": 160,
      "date": "2025-01",
      "period": "2025-01-01",
      ...
    }
  ]
}
```

**⚠️ ВАЖНО:** Точная структура данных зависит от конфигурации Project Lad. Агент автоматически адаптируется к структуре ответа и извлечет:
- Имя ресурса (из полей: `resource_name`, `item_name`, `work_name`, `name`)
- Период (из полей: `date`, `period`, `month`)
- Значение (из поля: `value`)

1. Проверьте доступные показатели: `"Покажи показатели проекта [ID]"`
2. Уточните точное название показателя в Project Lad
3. Возможно, показатель называется по-другому ("Resources", "Трудозатраты" и т.д.)
