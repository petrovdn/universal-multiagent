# О программе

## Universal Multi-Agent Platform

**Версия:** 1.0  
**Дата релиза:** 2025-01-12

---

## Описание

Universal Multi-Agent Platform — это платформа для создания и управления AI-агентами, построенная на базе LangGraph и ReAct архитектуры. Система предоставляет единый интерфейс для работы с различными сервисами через унифицированный протокол действий.

---

## Технологический стек

### Backend
- **Python 3.10+** — основной язык
- **LangGraph** — граф выполнения агентов
- **FastAPI** — веб-сервер
- **WebSocket** — real-time коммуникация
- **MCP (Model Context Protocol)** — интеграции

### Frontend
- **React 18+** — UI фреймворк
- **TypeScript** — типобезопасность
- **Zustand** — state management
- **Tailwind CSS** — стилизация

---

## Архитектура

Система построена на принципах:
- **ReAct (Reasoning + Acting)** — автономное выполнение задач
- **Unified Action Provider** — единый интерфейс для интеграций
- **Multi-Agent Orchestration** — координация нескольких агентов
- **Session-based Persistence** — изолированные сессии пользователей
