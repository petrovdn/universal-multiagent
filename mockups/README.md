# Mock-ups для параллельного выполнения

Эта папка содержит интерактивные HTML mock-ups для трех вариантов UI параллельного выполнения задач.

## Файлы

1. **parallel-execution-variant1-tabs.html** - Tabs (стиль Cursor Composer)
2. **parallel-execution-variant2-accordion.html** - Аккордеон (последовательный вывод)
3. **parallel-execution-variant3-minimal.html** - Минималистичный (максимально компактный)

## Как использовать

Просто откройте любой HTML файл в браузере - все стили и JavaScript встроены.

### Вариант 1: Tabs (Cursor-style)
- Переключение между ветками через вкладки
- Видна только активная ветка
- Подходит для небольших задач (2-3 ветки)

### Вариант 2: Аккордеон
- Все ветки видны одновременно
- Трехуровневое раскрытие: Ветка → Итерация → (Думание + Стриминг)
- Подходит для средних задач (2-5 веток)

### Вариант 3: Минималистичный
- Максимально компактный вид
- Автоматическое сворачивание успешных шагов
- Фокус на ошибках
- Подходит для долгих задач (5+ веток, 20+ шагов)

## Интерактивность

Все варианты поддерживают:
- ✅ Клик на ветку → раскрыть/свернуть ветку
- ✅ Клик на итерацию → раскрыть/свернуть итерацию
- ✅ Клик на "Думал" → раскрыть/свернуть thinking content
- ✅ Клик на "Стриминг" → раскрыть/свернуть streaming content

## Рекомендация

**Вариант 2 (Аккордеон)** с логикой автосворачивания из Варианта 3 - оптимальный баланс между информативностью и компактностью.
