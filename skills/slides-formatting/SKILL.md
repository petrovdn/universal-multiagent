## Когда активировать

Ключевые слова: "презентация", "слайды", "оформить", "красиво", "стиль", "профессионально", "дизайн"

Активируй этот skill когда пользователь:
- Просит создать презентацию
- Хочет профессиональный дизайн слайдов
- Просит оформить существующую презентацию
- Упоминает стили, темы, форматирование

## Приоритетные инструменты

1. **`create_presentation_batch`** ⚡ - **ОПТИМИЗИРОВАННОЕ** создание презентации с несколькими слайдами (используй для 5+ слайдов)
2. **`create_presentation`** - создание новой презентации (создаёт презентацию с одним пустым слайдом)
3. **`create_presentation_from_doc`** - создание презентации из Google Docs документа (автоматически оптимизировано)
4. **`create_slide`** - добавление новых слайдов (помни: первый слайд уже существует!)
5. **`insert_slide_text`** - вставка текста в слайд (вызывай ДВАЖДЫ: сначала для title, потом для body)
6. **`format_slide_text`** - форматирование текста (шрифт, размер, цвет, жирный/курсив)
7. **`format_slide_paragraph`** - форматирование параграфов (выравнивание, отступы, межстрочный интервал)
8. **`add_slide_image`** - добавление изображений
9. **`set_slide_background`** - установка фона слайда

## Workflow

### Пошаговое создание презентации (2-4 слайда)

📝 **ПОШАГОВЫЙ ПОДХОД (для 2-4 слайдов):**

1. **Создай презентацию:**
   - Используй `create_presentation` с названием
   - Получишь `presentation_id` и `first_slide_id` (первый слайд уже создан!)

2. **Оформи первый слайд:**
   - Вызови `insert_slide_text` с `target_element='title'` для заголовка
   - Вызови `insert_slide_text` с `target_element='body'` для содержимого
   - Примени форматирование через `format_slide_text`

3. **Добавь дополнительные слайды:**
   - Используй `create_slide` для каждого нового слайда
   - Помни: если пользователь просит N слайдов, создай только N-1 (первый уже есть!)
   - Используй `layout: "TITLE_AND_BODY"` для всех слайдов

4. **Оформи каждый слайд:**
   - Для каждого слайда вызови `insert_slide_text` ДВАЖДЫ:
     - Сначала с `target_element='title'` для заголовка слайда
     - Потом с `target_element='body'` для содержимого

5. **Примени единый стиль:**
   - Используй `format_slide_text` для заголовков (жирный, крупный шрифт)
   - Используй `format_slide_paragraph` для выравнивания и отступов
   - Используй `set_slide_background` для единого фона

⚠️ **ВАЖНО:** Презентация с 1 слайдом НЕ ЗАВЕРШЕНА! Добавь 3-5 слайдов с содержанием:
1. Титульный слайд (уже создан при `create_presentation`)
2. Введение/Обзор
3. Основные пункты (2-3 слайда)
4. Заключение

⚠️ **ПОРЯДОК:** `create_presentation` → (`create_slide` → `insert_slide_text` × 2) × N раз → FINISH

### Оптимизированное создание презентации (5+ слайдов)

**Используй `create_presentation_batch` для больших презентаций!**

⚡ **ОПТИМИЗИРОВАННЫЙ ПОДХОД (для 5+ слайдов):**

1. **Подготовь ВСЮ структуру заранее:**
   - Собери все тексты, заголовки, форматирование в памяти
   - Подготовь массив слайдов с полной информацией
   - **КРИТИЧЕСКИ ВАЖНО:** Каждый слайд ДОЛЖЕН иметь И заголовок (title), И содержимое (content)!
   - **ПО УМОЛЧАНИЮ:** Не указывай `theme` и `theme_source` - будет использована стандартная тема Google Slides
   - **ЕСЛИ ПОЛЬЗОВАТЕЛЬ ПРОСИТ "оформи как презентация 'X'":** Используй `theme_source="X"` - система найдёт презентацию в рабочей области и скопирует её стиль
   - **ПО УМОЛЧАНИЮ:** Добавляй 1-2 картинки на самые подходящие слайды (например, на 2-3 слайд с основным контентом)
   - **ЕСЛИ ПОЛЬЗОВАТЕЛЬ УКАЗАЛ:** Следуй инструкциям пользователя (например, "картинка на каждом слайде", "ровно 10 слайдов")

2. **Структура слайда для `create_presentation_batch`:**
   - `title`: Заголовок слайда (обязательно!)
   - `content`: Содержимое слайда (обязательно!):
     - Может быть строкой: `"Текст содержимого"`
     - Или массивом с подзаголовками и текстом:
       ```json
       [
         {"type": "subheading", "text": "Подзаголовок 1"},
         {"type": "text", "text": "Текст под подзаголовком 1. Минимум 3-4 предложения с подробным описанием."},
         {"type": "subheading", "text": "Подзаголовок 2"},
         {"type": "text", "text": "Текст под подзаголовком 2. Минимум 3-4 предложения с детальным объяснением."},
         {"type": "bullet", "text": "Пункт списка"}
       ]
       ```
     - Или простым массивом: `[{"type": "bullet", "text": "Пункт 1"}, {"type": "bullet", "text": "Пункт 2"}]`
   - `layout`: `"TITLE_AND_BODY"` (по умолчанию)
   - `theme`: (**ОБЯЗАТЕЛЬНО! ВСЕГДА указывай!**) Выбери тему по смыслу контента:
     * `"professional"` - для бизнеса, науки, образования (по умолчанию)
     * `"creative"` - для креативных проектов, маркетинга
     * `"minimal"` - для технических презентаций
     * `"dark"` - для IT-тематики
   - `theme_source`: (опционально) Имя презентации в рабочей области для копирования стиля (например, `"О собачках"`). Используй только если пользователь явно просит "оформи как презентация 'X'".
   - `image`: (опционально) конфигурация изображения для слайда. **ПО УМОЛЧАНИЮ добавляй 1-2 картинки на самые подходящие слайды** (например, на 2-3 слайд с основным контентом), если пользователь не указал иначе. Если пользователь указал требования (например, "картинка на каждом слайде", "по картинке на слайд"), следуй инструкциям:
     ```json
     {
       "search_query": "ancient rome architecture colosseum",
       "position": "right",
       "width": 4.0,
       "height": 3.0
     }
     ```
     - `search_query`: Поисковый запрос для Unsplash (на английском, например "ancient rome", "business meeting", "technology"). Выбирай релевантный запрос по содержанию слайда!
     - `position`: Позиция изображения - `"left"`, `"right"` (по умолчанию), или `"center"`
     - `width`: Ширина в дюймах (по умолчанию: 4.0)
     - `height`: Высота в дюймах (по умолчанию: 3.0)
   - `formatting`: (опционально) настройки форматирования

   ```json
       }
   ```

   **⚠️ КРИТИЧЕСКИ ВАЖНО - ВСЕГДА ДЕЛАЙ:**
   - **ВСЕГДА указывай `theme`** - выбирай автоматически по смыслу контента (professional, creative, minimal, dark)
   - **ПО УМОЛЧАНИЮ добавляй `image`** на 1-2 слайда с основным контентом (например, на 2-3 слайд)
   - Выбирай релевантный `search_query` на английском по содержанию слайда
   
   **ЕСЛИ ПОЛЬЗОВАТЕЛЬ УКАЗАЛ:**
   - Строго следуй инструкциям (например, "картинка на каждом слайде", "ровно 10 слайдов")
   - Если указано "по картинке на каждый слайд", добавляй `image` на каждый слайд

4. **Инструмент автоматически:**
   - Создаст все слайды одним batch-запросом
   - Вставит весь текст одним batch-запросом

### Форматирование существующей презентации

1. Получи `presentation_id` из запроса пользователя
2. Используй `get_presentation` для получения информации о слайдах
3. Примени форматирование к каждому слайду через `format_slide_text` и `format_slide_paragraph`

## Стили и рекомендации

### Заголовки слайдов
- Шрифт: Arial или Roboto
- Размер: 24-28pt
- Стиль: жирный (bold)
- Цвет: тёмный (чёрный или тёмно-синий)

### Основной текст
- Шрифт: Arial или Roboto
- Размер: 14-18pt
- Стиль: обычный (regular)
- Межстрочный интервал: 1.2-1.5

### Выравнивание
- Заголовки: по центру или слева
- Текст: слева (для читаемости)
- Списки: слева с отступами

### Цветовая схема
- Фон: светлый (белый или светло-серый)
- Текст: тёмный (чёрный или тёмно-серый)
- Акценты: используй корпоративные цвета если указаны

### Структура слайдов
- Первый слайд: титульный (только заголовок)
- Второй слайд: содержание (если много слайдов)
- Остальные: контентные слайды с заголовком и телом

### Добавление изображений к слайдам

🖼️ **Использование изображений:**

**ВАЖНО:**
- **ПО УМОЛЧАНИЮ:** Добавляй 1-2 картинки на самые подходящие слайды (обычно на 2-3 слайд с основным контентом)
- **ЕСЛИ ПОЛЬЗОВАТЕЛЬ УКАЗАЛ:** Следуй инструкциям (например, "картинка на каждом слайде", "по картинке на слайд", "ровно 10 слайдов")
- Если пользователь явно указал требования к количеству слайдов или картинок, строго следуй этим требованиям!

Для слайдов, которые выиграют от визуального контента, добавляй изображения через параметр `image`:

```json
{
  "title": "Древний Рим",
  "content": "...",
  "image": {
    "search_query": "ancient rome architecture colosseum",
    "position": "right",
    "width": 4.0,
    "height": 3.0
  }
}
```

**Рекомендации:**
- Используй изображения для слайдов про историю, архитектуру, природу, технологии, бизнес
- `search_query` должен быть на английском языке
- Выбирай релевантные запросы: "ancient rome", "business meeting", "technology innovation", "nature landscape"
- Позиция `"right"` подходит для большинства случаев (текст слева, изображение справа)
- Для титульных слайдов можно использовать `"center"` для больших изображений

**Примеры поисковых запросов:**
- История: "ancient rome", "medieval architecture", "renaissance art"
- Бизнес: "business meeting", "corporate office", "team collaboration"
- Технологии: "artificial intelligence", "computer technology", "innovation"
- Природа: "mountain landscape", "ocean waves", "forest nature"

### Применение тем к презентациям

⚠️ **КРИТИЧЕСКИ ВАЖНО:** **ВСЕГДА указывай `theme`** в `create_presentation_batch`! Выбирай тему автоматически по смыслу контента:
- `"professional"` - для бизнеса, науки, образования, истории (по умолчанию для большинства тем)
- `"creative"` - для креативных проектов, маркетинга, искусства
- `"minimal"` - для технических презентаций, программирования, математики
- `"dark"` - для IT-тематики, технологий, инноваций

**Если пользователь просит "оформи как презентация 'X'":**
1. Найди презентацию в рабочей области через `search_workspace_files` с `mime_type='application/vnd.google-apps.presentation'` и запросом `"X"`
2. Если найдена, используй её имя в параметре `theme_source` в `create_presentation_batch`
3. Если не найдена, создай презентацию со стандартной темой (не указывай `theme_source`)

**Пример:**
- Пользователь: "Создай презентацию про котов, оформи как презентация 'О собачках'"
- Твой план:
  1. `search_workspace_files(query="О собачках", mime_type="application/vnd.google-apps.presentation")`
  2. Если найдена (например, название "О собачках"), то `create_presentation_batch(title="...", slides=[...], theme_source="О собачках")`
  3. Если не найдена, то `create_presentation_batch(title="...", slides=[...])` (без `theme_source`)

**Доступные темы (ВЫБИРАЙ АВТОМАТИЧЕСКИ):**
- `"professional"` - для бизнес-презентаций, отчетов, деловых встреч, истории, науки, образования ← **ИСПОЛЬЗУЙ ПО УМОЛЧАНИЮ**
- `"creative"` - для маркетинговых презентаций, креативных проектов, портфолио, искусства
- `"minimal"` - для академических презентаций, научных докладов, технических материалов
- `"dark"` - для IT-презентаций, технологий, инноваций

**Примеры автоматического выбора темы:**
- "презентация про древний Рим" → `theme: "professional"` (история)
- "презентация про наш стартап" → `theme: "creative"` (бизнес/маркетинг)
- "презентация про алгоритмы сортировки" → `theme: "minimal"` (технические)
- "презентация про AI и ML" → `theme: "dark"` (технологии)

**Пример:**
```json
{
  "title": "Древний Рим",
  "theme": "professional",  ← ОБЯЗАТЕЛЬНО!
  "slides": [...]
}
```

⚠️ **КРИТИЧЕСКИ ВАЖНО:** Параметр `theme` **ОБЯЗАТЕЛЕН** для всех вызовов `create_presentation_batch`! **ВСЕГДА** указывай theme, выбирая по смыслу контента!

## Требования к содержимому слайдов

### Критически важные требования

⚠️ **ОБЯЗАТЕЛЬНО:** Каждый слайд ДОЛЖЕН содержать:
- `title`: Заголовок слайда (обязательно!)
- `content`: Содержимое слайда (обязательно!)

❌ **НЕПРАВИЛЬНО:**
```json
{
  "title": "Заключение",
  "content": "Итоги"
}
```

✅ **ПРАВИЛЬНО:**
```json
{
  "title": "Заключение",
  "content": "Итоги и выводы. Минимум 5-6 строк текста с подробными выводами, обобщениями и рекомендациями. В заключении нужно сказать, что 7 чудес света - это уникальные архитектурные памятники древности, которые демонстрируют мастерство и гений человеческой цивилизации. Каждое из них представляет собой не только техническое достижение, но и культурное наследие, которое продолжает вдохновлять людей по всему миру."
}
```

### Требования к объему контента

- **Титульный слайд:** Описание презентации и её цели (2-3 предложения)
- **Введение:** Подробное введение в тему с основными концепциями (3-4 предложения)
- **Основные слайды:** 
  - Если используются подзаголовки: **под КАЖДЫМ подзаголовком должно быть минимум 3-4 предложения** с подробным описанием
  - Если используются списки: детальное описание каждого пункта (минимум 3-4 предложения или 3-5 пунктов списка)
- **Заключение:** **МИНИМУМ 5-6 СТРОК** текста с подробными выводами, обобщениями и рекомендациями

⚠️ **КРИТИЧЕСКИ ВАЖНО:** Если в слайде есть подзаголовки (subheading), под КАЖДЫМ подзаголовком должен быть развернутый текст из 3-4 предложений!

### Примеры правильного контента

**Плохо (недостаточно информации):**
```json
{
  "title": "Заключение",
  "content": "Итоги"
}
```

**Хорошо (достаточно информации):**

## Важные замечания

⚠️ **КРИТИЧНО:** `create_presentation` создаёт презентацию с ОДНИМ пустым слайдом. Если пользователь просит N слайдов, создай только N-1 дополнительных через `create_slide`.

⚠️ **ПАТТЕРН:** Для каждого слайда вызывай `insert_slide_text` ДВАЖДЫ:
1. С `target_element='title'` для заголовка
2. С `target_element='body'` для содержимого

⚠️ **ФОРМАТИРОВАНИЕ:** Применяй форматирование ПОСЛЕ вставки текста, используя `format_slide_text` с правильным `page_id` и `element_id`.

⚠️ **СОДЕРЖИМОЕ:** Всегда генерируй развернутое содержимое для каждого слайда. Особенно важно для заключительных слайдов - минимум 5-6 строк текста с подробными выводами.

### Пример 2: Пошаговое создание (для небольших презентаций)

**Запрос:** "Создай презентацию на 3 слайда"

1. `create_presentation(title="Моя презентация")` → получишь presentation_id и first_slide_id
2. `insert_slide_text(page_id=first_slide_id, text="Заголовок", target_element='title')`
3. `insert_slide_text(page_id=first_slide_id, text="Содержимое", target_element='body')`
4. `create_slide(presentation_id=..., layout="TITLE_AND_BODY")` → слайд 2
5. `create_slide(presentation_id=..., layout="TITLE_AND_BODY")` → слайд 3
6. Для каждого слайда: `insert_slide_text` дважды (title + body)
7. Применить форматирование через `format_slide_text`
