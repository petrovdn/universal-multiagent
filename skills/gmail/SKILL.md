## Когда активировать

Ключевые слова: "письмо", "почта", "email", "gmail", "отправить", "inbox"

Активируй этот skill когда пользователь:
- Просит проверить почту или непрочитанные письма
- Хочет найти конкретное письмо
- Просит отправить письмо
- Просит создать черновик

## Приоритетные инструменты

1. **`list_emails`** — получить список писем (для "покажи почту")
2. **`search_emails`** — поиск с фильтрами (для "найди письма от...")
3. **`read_email`** — прочитать конкретное письмо
4. **`send_email`** — отправить письмо (⚠️ требует подтверждения)
5. **`draft_email`** — создать черновик

## Workflow

### Проверка почты
1. Используй `list_emails` с `max_results=10` для быстрого обзора
2. Для фильтрации: `search_emails` с query (например, `is:unread`)

### Поиск писем
1. Используй `search_emails` с query
2. Примеры query:
   - `from:boss@company.com` — письма от определённого адреса
   - `subject:отчёт` — по теме
   - `after:2024/01/01` — после даты
   - `is:unread` — непрочитанные

### Отправка письма
1. ⚠️ ВАЖНО: Подтверди у пользователя получателя и содержимое
2. Используй `send_email` с параметрами to, subject, body

## Guidelines

1. **Валидация email адресов:**
   - Всегда проверяй email адреса перед отправкой
   - Используй понятный, профессиональный язык

2. **Форматирование писем:**
   - Используй понятные темы (subject lines)
   - Форматируй для читаемости (переносы строк, списки)
   - Используй bullet points когда нужно

3. **Поиск писем:**
   - Используй синтаксис Gmail search эффективно:
     - `from:email@example.com` — письма от адреса
     - `subject:текст` — по теме
     - `after:2024/01/01` — после даты
     - `before:2024/12/31` — до даты
     - `is:unread` — непрочитанные
   - Для относительных дат ("последние 3 дня") используй соответствующие фильтры
   - Для абсолютных дат используй формат YYYY/MM/DD

4. **Чувствительные операции:**
   - Подтверждай детали перед выполнением
   - Предоставляй понятные сводки результатов поиска
   - Обрабатывай ошибки gracefully, предлагай альтернативы

## Важные замечания

⚠️ **Отправка писем** — требует явного запроса пользователя и подтверждения
⚠️ **Поиск за период** — используй `after:` и `before:` в query
⚠️ **Email адреса** — всегда валидируй перед отправкой
⚠️ **Профессиональный тон** — используй деловой стиль в письмах
