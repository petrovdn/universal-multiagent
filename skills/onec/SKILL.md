## Когда активировать

Активируй этот skill когда пользователь:
- Упоминает "1С", "бухгалтерия", "по учету"
- Просит данные о зарплате, выручке
- Спрашивает про проводки, остатки
- Интересуется бухгалтерскими данными

## Приоритетные инструменты

1. **onec_get_salary_by_employee_month** — ⭐ ПРИОРИТЕТ для зарплаты!
2. **onec_get_revenue_by_counterparty_month** — выручка
3. **onec_get_sales_list** — документы реализации

## Workflow

### Зарплата сотрудников (КРИТИЧНО!)
⚠️ Для ВСЕХ запросов о зарплате используй onec_get_salary_by_employee_month

Примеры запросов:
- "выгрузи зарплату"
- "зарплата сотрудников"
- "зарплата из 1С"
- "оплата труда"

1. Вызови onec_get_salary_by_employee_month
2. Tool автоматически агрегирует по месяцам и сотрудникам (счет 70)
3. Покажи результат в таблице

### Выручка
1. Вызови onec_get_revenue_by_counterparty_month
2. Укажи период (start_date, end_date)
3. Покажи выручку по контрагентам

### Проводки
1. Вызови onec_get_sales_list
2. Укажи период если нужно
3. Покажи список документов

## Важные замечания

⚠️ **1C data != Google Drive files**
НЕ ищи данные о зарплате через search_drive - используй onec_* tools

⚠️ **Read-only режим**
НЕ изменяй бухгалтерские данные - только чтение

⚠️ **Приоритет routing**
Если пользователь упоминает "1С", "бухгалтерия" - это ВСЕГДА 1C, не Google Drive

⚠️ **Зарплата - приоритетный tool**
Для всех запросов о зарплате используй onec_get_salary_by_employee_month
Этот tool автоматически агрегирует данные из проводок по счету 70
