## Когда активировать

Ключевые слова: "подготовь к встрече", "информация о встрече", "что по встрече"

Активируй этот skill когда пользователь:
- Просит подготовить информацию к встрече
- Хочет контекст по предстоящему событию
- Спрашивает что известно об участниках встречи

## Workflow

### Последовательный сбор данных

1. **Calendar Agent:**
   - Найти встречу по названию или времени
   - Получить список участников

2. **Gmail Agent:**
   - Найти переписку с участниками за последнюю неделю
   - `search_emails` с `from:participant@email.com`

3. **Workspace Agent:**
   - Найти документы связанные с темой встречи

4. **Docs Agent (если найдены):**
   - Прочитать ключевые документы

### Синтез результата

Сформировать брифинг к встрече с контекстом.
