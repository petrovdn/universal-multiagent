## Когда активировать

Ключевые слова: "фокус", "обзор дня", "что важного", "мой день", "задачи на сегодня"

Активируй этот skill когда пользователь:
- Просит показать фокус дня
- Хочет обзор важных дел
- Спрашивает что сегодня важного
- Просит сводку на день

## Workflow

### Параллельный сбор данных

1. **Gmail Agent:**
   - `list_emails` с query `is:unread` — непрочитанные
   - Или `search_emails` с `is:important` — важные

2. **Calendar Agent:**
   - `get_calendar_events` с date_range="today" — встречи сегодня

3. **Sheets Agent (опционально):**
   - Если есть трекер задач — получить данные

### Синтез результата

Объединить результаты в структурированную сводку:
- Количество непрочитанных писем + важные отправители
- Список встреч на сегодня с временем
- Ключевые задачи (если есть)

## Пример вывода

```
📋 **Фокус на сегодня**

📧 **Почта:** 5 непрочитанных
   - От: boss@company.com — "Отчёт Q4" (важное)
   - От: client@example.com — "Вопрос по проекту"

📅 **Встречи:**
   - 10:00 — Стендап (30 мин)
   - 14:00 — Встреча с клиентом (1 час)
   - 16:30 — Ревью проекта (45 мин)

✅ **Приоритеты:**
   - Ответить на письмо boss@company.com
   - Подготовиться к встрече с клиентом
```
